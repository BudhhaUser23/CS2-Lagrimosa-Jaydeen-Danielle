# Fare Calculator with Input Validation

## Description
This program calculates for the fare of a person or a group of people using the distance and the number of people and also uses input validation to prevent errors.

## Version 1 - Original code without input validation
- Input: Accepts the passenger's name, the distance they are gonna travel, and the number of passengers.
- Process: It checks first the input if it is not blank and is the correct types, then calculates using the distance, the number of passengers, and the already given fare rate.
- Output: It asks for a re-entry if the entered input does not follow the rules. If there are no mistakes in the input, then it displays the total amount they need to pay.
- Does include input validation.
