# Fare Calculator

## Description
This program calculates for the fare of a person or a group of people using the distance and the number of people.

## Version 1 - Original code without input validation
- Input: Accepts the passenger's name, the distance they are gonna travel, and the number of passengers.
- Process: Calculates using the distance, the number of passengers, and the already given fare rate.
- Output: Total amount they need to pay.
- Does not include input validation.
